# Changelog

## 2.0.0

- Added public SaaS, Supabase-authenticated Free/Pro workspaces, and optional
  Razorpay subscription integration.
- Kept arbitrary public analysis limited to deterministic Unicode artifacts;
  configured KGW/SynthID workflows remain advanced/reference tooling.
- Added production deployment guidance, privacy/retention documentation,
  explicit production configuration validation, trusted-proxy opt-in, request
  body limits, and safer exception logging.

Live billing remains intentionally unavailable
until provider credentials and, for Razorpay, KYC activation are complete.
